# User Stories

## Authentication

As a user,

I want to register

So that I can use the application.

---

As a user,

I want to login securely

So that my trips remain private.

---

## Trips

As a user,

I want to create a trip

So that I can plan my vacation.

---

As a user,

I want to edit my trip

So that I can update travel details.

---

## Expenses

As a user,

I want to record expenses

So that I can stay within my budget.

---

## Documents

As a user,

I want to upload tickets

So that I can access them anytime.
