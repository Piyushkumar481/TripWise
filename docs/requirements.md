# TripWise – Smart Travel Planning Platform

## Overview

TripWise is a web application that helps users plan, organize, and manage their trips. Users can create trips, manage expenses, upload travel documents, maintain packing checklists, and monitor travel budgets from a single dashboard.

---

## Objectives

- Simplify trip planning
- Track travel expenses
- Store travel documents securely
- Organize itineraries
- View travel analytics
