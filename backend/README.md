# TripWise Backend

## Overview

TripWise is a smart travel planning platform built using Java Spring Boot and PostgreSQL.

The backend provides REST APIs for authentication, trip management, itinerary planning, expense tracking, document management, and dashboard information.

## Technologies

- Java 21
- Spring Boot 4.1.0
- Spring Security
- JWT Authentication
- BCrypt
- Spring Data JPA
- Hibernate
- PostgreSQL
- Maven
- Swagger / OpenAPI
- Docker
- Azure
